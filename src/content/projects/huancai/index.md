幻彩面向服装与电商图片生产，将多种图像任务整理为统一的 Web 工作台。

## 项目重点

- 支持换装、买家秀和背景替换。
- 覆盖商品改款、图片裂变和高清放大。
- 以 TypeScript 为主要开发语言。
- 将多个分散的生成步骤收敛为可重复使用的操作流程。

项目详情和当前支持的模块以 GitHub 仓库为准。
