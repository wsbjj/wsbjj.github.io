Doc AI Compare 的前端围绕项目材料审查流程设计，从文档上传开始，连接智能比对、知识库检索和报告展示。

## 项目重点

- 使用 Nuxt 与 Vue 构建审查工作台。
- 支持上传材料并查看比对任务状态。
- 整合知识库检索与结构化报告。
- 与公开的 Spring Boot 服务端仓库配合使用。

项目详情和接口要求以 GitHub 仓库为准。
