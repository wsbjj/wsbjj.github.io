S-OpenCow 面向桌面端 Agent 工作流，将任务派发、多 Agent 并行协作、技能管理和即时通讯接入集中到同一个应用中。

## 项目重点

- 围绕任务而不是单次对话组织 Agent 工作。
- 支持多 Agent 并行执行与结果汇总。
- 提供技能市场和即时通讯集成入口。
- 主要使用 TypeScript，公开仓库采用 Apache License 2.0。

项目详情、运行方式和最新改动以 GitHub 仓库为准。
