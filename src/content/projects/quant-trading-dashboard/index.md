Quant Trading Dashboard 采用本地优先的方式组织股票关注列表、行情缓存、催化剂事件和 LLM 分析结果。

## 项目重点

- 管理关注标的和本地行情缓存。
- 汇集催化剂事件并生成分析结果。
- 输出交易情景报告，辅助进一步研究。
- 主要使用 TypeScript 开发。

该项目仅展示软件实现，不构成投资建议。详情以 GitHub 仓库为准。
