Prompt Optimizer 将飞书日报内容交给大模型分析，并输出多时间尺度的结构化总结。

## 项目重点

- 定时提取日报内容。
- 生成日总结、周总结与月总结。
- 输出结构化表现评分。
- 将结果接回飞书工作流。
