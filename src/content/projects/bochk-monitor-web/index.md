该项目将预约状态监控和 Web 管理界面组合在一个 Flask 应用中。

## 项目重点

- 自动监控公开预约放号状态。
- 发现可用名额后发送邮件通知。
- 提供配套 Web 界面。
- 运行与使用要求以仓库说明为准。
