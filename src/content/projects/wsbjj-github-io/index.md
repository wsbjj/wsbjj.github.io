个人站点源码仓库，负责组织个人介绍、公开项目索引、项目详情、搜索以及 GitHub Pages 自动发布流程。

## 项目重点

- 使用 Astro 生成静态页面。
- 完整收录当前公开 GitHub 仓库。
- 支持响应式布局、搜索与明暗主题。
- 通过 GitHub Actions 自动部署到 Pages。
