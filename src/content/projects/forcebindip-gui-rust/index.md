该项目使用 Rust 与 `native-windows-gui` 重写 ForceBindIP GUI，并明确保留对原作者与 ForceBindIP 的署名。

## 项目重点

- 中文和英文界面切换。
- 兼容原 AutoIt 版本的配置格式。
- 自动检测网卡并运行指定应用。
- 提供 ForceBindIP 下载与安装入口。
