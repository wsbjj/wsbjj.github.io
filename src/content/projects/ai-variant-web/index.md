AI Variant Web 将商品图片改款拆分为可观察的任务阶段，包括参考图分析、产品图分析、Logo 特征复用、提示词融合和最终出图。

## 项目重点

- 通过任务编排管理多阶段图像工作流。
- 前端以 TypeScript 为主，后端结合 Python。
- 将分析结果、提示词和出图状态集中展示。
- 面向实际商品视觉生产流程设计。

项目详情、部署要求和支持的工作流以 GitHub 仓库为准。
