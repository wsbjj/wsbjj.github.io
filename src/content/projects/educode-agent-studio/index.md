EduCode Agent Studio 将知识库、代码执行和 AI 诊断能力整合为桌面端学习工具。

## 项目重点

- 导入课程或个人知识库。
- 执行代码并提供 AI 诊断与修复建议。
- 记录错题并支持后续复盘。
- 汇总学习过程形成学习画像。

项目详情和当前运行方式以 GitHub 仓库为准。
