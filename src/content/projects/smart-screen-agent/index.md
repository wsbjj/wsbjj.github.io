Smart Screen Agent 将简历解析、岗位要求提取、候选人评分和结果导出组合为桌面端筛选流程。

## 项目重点

- 统一处理简历和岗位要求。
- 通过 AI 评分辅助候选人比较。
- 支持模型路由与结构化结果导出。
- 主要使用 TypeScript 构建桌面端体验。

项目详情和最新功能以 GitHub 仓库为准。
