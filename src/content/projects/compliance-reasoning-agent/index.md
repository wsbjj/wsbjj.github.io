该项目通过 LangGraph 编排推理流程，并使用 MCP 接入外部专利数据库与市场趋势工具，面向业务决策生成结构化分析简报。

## 项目重点

- 将多步推理过程组织为可追踪的 Agent 工作流。
- 接入外部专利与市场信息来源。
- 输出专利壁垒、市场热度和准入时机等分析维度。
- 主要使用 Python，公开仓库采用 MIT License。

项目详情、配置方式和当前能力以 GitHub 仓库为准。
